= 將失效的 FAS2700 開機媒體退回 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更換 FAS2700 系統上的開機媒體後，請依照套件隨附的 RMA 說明將故障零件退回 NetApp。

如需更多資訊，請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面。FAS2700 系統僅支援手動開機媒體還原程序。不支援自動開機媒體恢復。
