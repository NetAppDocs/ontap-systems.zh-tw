= AFF A400 機箱更換工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要更換 AFF A400 系統的機箱，首先要關閉控制器，將硬體移至替換機箱，然後完成系統還原。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:chassis-replace-shutdown.html["關閉控制器"]
[role="quick-margin-para"]
關閉控制器以安全地進行機箱維護。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:chassis-replace-move-hardware.html["更換機箱"]
[role="quick-margin-para"]
將故障機箱中的風扇、磁碟機和控制器模組移至替換機箱。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:chassis-replace-complete-system-restore-rma.html["完成機箱更換"]
[role="quick-margin-para"]
透過驗證 HA 狀態、在需要時切換回聚合，以及將故障機箱退回 NetApp，完成更換程序。
