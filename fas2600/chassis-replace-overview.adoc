= 在更換 FAS2600 系統機箱之前，請先檢閱相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更換 FAS2600 系統中的機箱之前，請審查將電源供應、硬碟機和控制器模組從故障機箱移至新機箱的要求，以及將設備機架或系統機櫃中的故障機箱更換為相同型號的新機箱的要求。

系統中的所有其他組件必須正常運作。如果發生故障，請聯絡技術支援。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序的撰寫假設是您將所有磁碟機和控制器模組或模組移至新機箱、而且機箱是NetApp的新元件。
* 此程序會造成中斷。對於雙節點叢集，將導致服務完全停電；對於多節點叢集，將導致服務部分停電。
