= 在自動開機恢復過程結束後，將故障的 AFF A900 開機媒體歸還給 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的AFF A900系統中的某個元件發生故障，請將故障元件退回給NetApp。請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面以獲取更多資訊。
