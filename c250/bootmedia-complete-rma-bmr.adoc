= 在自動開機恢復過程結束後，將故障的 AFF C250 開機媒體歸還給 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 AFF C250 系統中更換開機媒體後，請依照套件隨附的 RMA 說明將故障零件退回 NetApp。如需詳細資訊，請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面。
