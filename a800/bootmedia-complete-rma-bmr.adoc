= 在自動開機恢復過程結束後，將故障的 AFF A800 開機媒體歸還給 NetApp。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 AFF A800 系統中完成故障開機媒體的自動開機恢復程序後，請將故障元件退回 NetApp。詳情請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面。
