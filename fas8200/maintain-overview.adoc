= 了解如何維護 FAS8200 儲存系統
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以對 FAS8200 儲存系統元件執行維護程序，包括開機媒體、機箱、控制器、DIMM 和電源供應。



[[boot-media]]
== 開機媒體

開機媒體會儲存一組主要和次要的開機映像檔案、供系統在開機時使用。



[[caching-module]]
== 快取模組

當系統登錄單一 AutoSupport （ ASUP ）訊息指出模組已離線時、您必須更換控制器的快取模組。



[[chassis]]
== 機箱

機箱是實體機箱、可容納所有控制器元件、例如控制器 /CPU 單元、電源供應器和 I/O



[[controller]]
== 控制器

控制器由主機板、韌體和軟體組成。它控制磁碟機並執行 ONTAP 功能。



[[dimm]]
== DIMM

如果存在記憶體不相符的情況、或是有故障的DIMM、則必須更換DIMM（雙列直插式記憶體模組）。



[[drive]]
== 磁碟機

磁碟機是提供資料實體儲存媒體的裝置。



[[nvmem-battery]]
== NVMEM電池

控制器隨附電池、當AC電源故障時、會保留快取的資料。



[[pcie-card]]
== PCIe卡

PCIe （周邊元件互連高速）卡是插入主機板 PCIe 插槽的擴充卡。



[[power-supply]]
== 電源供應器

電源供應器可在控制器機櫃中提供備援電源。



[[real-time-clock-battery]]
== 即時時鐘電池

即時時鐘電池會在電源關閉時保留系統日期和時間資訊。
