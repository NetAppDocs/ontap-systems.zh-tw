= 在更換 FAS8200 系統機箱之前，請先檢閱相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更換 FAS8200 系統中的機箱之前，請確認所有其他組件都運作正常，且更換的機箱是NetApp同一型號的全新組件。此操作需要將電源供應、風扇和控制器模組移至新機箱，並且會造成系統中斷，在雙控制器叢集中會導致完全服務停電，在多節點叢集中會導致部分服務停電。

系統中的所有其他組件必須正常運作。如果發生故障，請聯絡技術支援。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序的撰寫假設是您將控制器模組或模組移至新機箱、而且機箱是NetApp的新元件。
* 此操作會造成服務中斷。對於雙控制器叢集，會導致服務完全中斷；對於多節點叢集，則會導致服務部分中斷。
