= 在自動開機恢復程序結束後，將故障的 FAS8300 或 FAS8700 開機媒體退回 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的FAS8300或FAS8700系統中的某個元件發生故障，請將故障元件退回給NetApp。請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面以獲取更多資訊。
