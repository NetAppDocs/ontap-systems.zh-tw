= 在更換 FAS8300 或 FAS8700 系統的機箱之前，請先審查相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更換 FAS8300 或 FAS8700 系統中的機箱之前，系統中的所有其他組件必須運作正常；否則，您必須聯絡技術支援。此程序適用於所有 ONTAP 版本，但會導致雙控制器叢集完全停電，以及多節點叢集部分停電。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序會造成中斷：雙控制器叢集將發生完全服務停電，多節點叢集將發生部分停電。
