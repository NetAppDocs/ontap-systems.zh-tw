= 手冊開機恢復程序結束後，將故障的 FAS2820 開機媒體退回給 NetApp。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更換 FAS2820 系統中的開機媒體後，請依照套件隨附的 RMA 說明將故障零件退回 NetApp。

如套件隨附的RMA指示所述、將故障零件退回NetApp。如 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]需詳細資訊、請參閱頁面。
