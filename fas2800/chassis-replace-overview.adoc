= 在更換 FAS2820 系統機箱之前，請先審查相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要更換 FAS2820 系統中的機箱，請將電源供應器、硬碟和控制器模組從故障機箱移至新機箱。然後，將故障機箱從設備機架或系統機櫃中取出，並將相同型號的新機箱安裝到原位。

系統中的所有其他組件必須正常運作。如果發生故障，請聯絡技術支援。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序的撰寫假設是您將所有磁碟機和控制器模組或模組移至新機箱、而且機箱是NetApp的新元件。
* 此操作會造成服務中斷。對於雙控制器叢集，此操作會導致服務完全停電；對於多節點叢集，則會導致服務部分停電。
