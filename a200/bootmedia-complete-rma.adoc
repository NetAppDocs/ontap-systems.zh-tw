= 將故障的 AFF A200 開機媒體退回 NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
更換開機媒體後，請依照套件隨附的 RMA 說明，將故障的 AFF A200 開機媒體退回給 NetApp。如需更多資訊，請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面。
