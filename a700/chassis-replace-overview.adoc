= 更換 AFF A700 機箱前，請先查看相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更換 AFF A700 系統中的機箱之前，請審查成功更換所需的條件。機箱更換程序會將所有元件從受損機箱移至替換機箱，此程序會造成系統中斷。

系統中的所有其他元件都必須正常運作；否則、您必須聯絡技術支援部門。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序會造成中斷。對於雙節點叢集、您將會在多節點叢集中發生完整的服務中斷和部分中斷。
