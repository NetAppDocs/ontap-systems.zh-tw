= 了解如何維護 AFF A150 儲存系統
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
維護 AFF A150 儲存系統的硬體，以確保其長期可靠性和最佳效能。定期執行維護任務，例如更換故障組件，以協助防止停機和資料遺失。



[[boot-media]]
== 開機媒體

開機媒體會儲存一組主要和次要的開機映像檔案、供系統在開機時使用。



[[chassis]]
== 機箱

機箱是實體機箱、可容納所有控制器元件、例如控制器 /CPU 單元、電源供應器和 I/O



[[controller]]
== 控制器

控制器由主機板、韌體和軟體組成。它控制磁碟機並執行 ONTAP 功能。



[[dimm]]
== DIMM

如果存在記憶體不相符的情況、或是有故障的DIMM、則必須更換DIMM（雙列直插式記憶體模組）。



[[drive]]
== 磁碟機

磁碟機是提供資料實體儲存媒體的裝置。



[[nvram-battery]]
== NVRAM電池

控制器隨附電池、當AC電源故障時、會保留快取的資料。



[[power-supply]]
== 電源供應器

電源供應器可在控制器機櫃中提供備援電源。



[[real-time-clock-battery]]
== 即時時鐘電池

即時時鐘電池會在電源關閉時保留系統日期和時間資訊。
