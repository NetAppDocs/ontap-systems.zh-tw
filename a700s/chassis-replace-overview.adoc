= 更換 AFF A700s 機箱前，請先查看相關要求。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在更換 AFF A700s 系統中的機箱之前，請先審查成功更換所需的條件。機箱更換程序會將控制器模組和 SSD 磁碟機從故障機箱移至新機箱，此程序會造成系統中斷。

系統中的所有其他元件都必須正常運作；否則、您必須聯絡技術支援部門。

* 您可以將此程序用於ONTAP 系統支援的所有版本的功能。
* 此程序的撰寫假設是您將SSD和控制器模組移至新機箱、而更換機箱是NetApp的新元件。
* 此程序會造成中斷。對於雙節點叢集、您將會在多節點叢集中發生完整的服務中斷和部分中斷。
