= 在 FAS9500 系統中熱插拔 LED USB 模組
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS9500 系統中的 LED USB 模組提供與主控台連接埠的連接以及系統狀態顯示。更換該模組無需工具，也不會中斷服務。



[[step-1-replace-the-led-usb-module]]
== 步驟1：更換LED USB模組

.步驟
. 移除舊的LED USB模組：
+
.動畫-移除/安裝LED/USB模組
video::bc46a3e8-6541-444e-973b-ae78004bf153[panopto]
+
image::../media/drw_9500_remove_replace_LED_mod.svg[更換 LED 模組]

+
[cols="20%,80%"]
|===


 a| 
image::../media/icon_round_1.png[編號 1]
 a| 
鎖定按鈕



 a| 
image::../media/icon_round_2.png[編號 2]
 a| 
USB LED模組

|===
+
.. 卸下擋板後、將LED USB模組定位在機箱正面左下側。
.. 滑入栓鎖以部分退出模組。
.. 將模組從支架中拉出、以將其從中間背板上拔下。請勿將插槽留白。


. 安裝新的LED USB模組：
+
.. 將模組對準插槽，使模組角落的凹槽靠近機箱上的滑動閂鎖。插槽可防止模組安裝反裝。
.. 將模組推入支架、直到與機箱齊面完全就位。
+
當模組安全地連接到中板時，會發出咔嗒聲。







[[step-2-return-the-failed-component]]
== 步驟2：傳回故障元件

. 如套件隨附的RMA指示所述、將故障零件退回NetApp。如 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"^]需詳細資訊、請參閱頁面。
