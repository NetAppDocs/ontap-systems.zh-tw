= 在自動開機恢復過程結束後，將故障的 AFF A250 開機媒體歸還給 NetApp。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的 AFF A250 系統中的某個元件發生故障，請將故障元件退回 NetApp。如需詳細資訊，請參閱 https://mysupport.netapp.com/site/info/rma["零件退貨與更換"]頁面。
